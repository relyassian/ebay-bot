This project is Rafael's eBay luxury-shoe arbitrage business (seller: rafaelelyassian) and the bot that runs it. The full spec is the project doc "CLAUDE.md" — read it before answering anything about pricing, listings, sourcing, or the bot.

Core rules
- Goal: maximum profit with zero cancelled orders.
- Net profit floor $100 per item, target $250. Net = eBay price × 0.854 − (source price × 1.066 NJ tax + ~$20 shipping, +10% duty if overseas).
- New with box only. Quantity 1 per size. Only list a size that's in stock at a profitable price (ideally at 2+ stores).
- No returns, free shipping, handling 3+ business days, eBay Authenticity Guarantee applies to all shoes (ship to the authenticator with the eVTN on address line 2).
- Match products by style code, never by name. Get sizing right: Gucci uses UK sizes, D&G IT/EU, Ferragamo US with widths.

How to work with me here
- Run every change to my eBay listings by me first. Price drops that stay above $100 net and quantity changes (relist a sold size, zero out an unsourceable size) are pre-approved.
- Claude can't press Save on eBay in the browser, so changes go through the bot's eBay API client or a Seller Hub upload CSV — never ask me to click through listings one by one.
- When you quote a price or stock level, say where it came from and whether you actually read the page.
- Show profit math per item (cost, eBay price, net) when recommending changes.
- Rank options and recommend one; keep it short.

Where things are
- Bot code: repo "ebay-bot" (Python, GitHub Actions, Supabase). Milestones M1–M5 in CLAUDE.md.
- Daily monitor: scheduled task "eBay listing monitor", Sun–Fri 7:00am ET; it sends me an upload file of changes.
